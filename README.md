# 🤖 Telegram Daily Planner & Habit Tracker Bot (@Dailyplanhabittrackbot)

A production-ready, fully asynchronous Telegram Bot for daily planning, habit tracking, reminders, and productivity analytics. Built with Python 3.12+ and `python-telegram-bot` v22+.

## 🚀 Features
- **Task Management**: Categorized priorities, auto-archiving, search, and due dates.
- **Habit Tracking**: Daily/weekly habits, streaks, pause/resume, and logging.
- **Smart Reminders**: Background APScheduler for seamless delivery.
- **Productivity Stats**: Streak tracking, completion rates, and analytics summaries.
